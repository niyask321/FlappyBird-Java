# 🐦 Flappy Bird – Java

A simple and fun **Flappy Bird-style game built using Java Swing**.  
The game features keyboard and mouse controls, randomly generated pipes, collision detection, scoring, and a restart system.

---

## 🎮 Features

- 🐦 Simple Flappy Bird gameplay
- 🎯 Score tracking
- 🟢 Randomly generated pipe positions
- 💥 Collision detection
- 🖱️ Mouse click controls
- ⌨️ Keyboard controls
- 🔄 Restart after Game Over
- ☁️ Simple animated-game-style environment
- 🖥️ Built with Java Swing
- ⚡ Lightweight and easy to run

---

## 🕹️ Controls

| Action | Control |
|--------|---------|
| Start Game | `SPACE` / Mouse Click |
| Flap | `SPACE` / Mouse Click |
| Restart | `R` / Mouse Click after Game Over |

---

## 🛠️ Technologies Used

- **Java**
- **Java Swing**
- **AWT**
- **Java Timer**
- **Random Number Generation**
- **Event Handling**
- **Collision Detection**
